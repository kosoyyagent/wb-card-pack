# wb-card-pack

Генератор заготовок наполнения карточек Wildberries из Excel-спецификации.

Вход: xlsx/csv с товарами — колонки артикул/название/бренд/категория +
любые свободные колонки-характеристики (материал, цвет, размер, назначение...).

Выход `cards_out.xlsx`:

| поле | как строится |
|---|---|
| seo_заголовок | название + бренд, обрезан до 60 знаков |
| описание | 2-3 связных предложения из характеристик + назначение |
| ключевые_слова | до 20 токенов из всех полей, бренд/категория первыми |
| характеристики_json | все свободные колонки → JSON |

## Запуск

```bash
pip install -r requirements.txt
python wb_card_pack.py spec.xlsx [--out cards_out.xlsx]
```

Демо-вход и реальный выход — `docs/demo_spec.xlsx` → `docs/cards_out.xlsx`.

## Честно про границы

Это генератор **заготовки**: заголовки и описания связные и без воды,
но финальную вычитку/вкус делает человек — инструмент снимает 90%
рутины заполнения, а не заменяет копирайтера. Колонки распознаются
по именам: название/наименование, бренд, категория, артикул, назначение/
применение — остальные уходят в характеристики.
